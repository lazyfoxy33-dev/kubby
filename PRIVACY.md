## Data Collection

Kubby **does not collect any personal data**.

- **Network**: Kubby does not connect to the internet and makes no network requests.
- **Files**: Kubby temporarily holds file references only when the user drags files in, solely for display and move operations. All references are released immediately when the app is closed or the shelf is cleared. File contents are never read, copied, or uploaded.
- **Accessibility**: Kubby requests Accessibility permission solely to detect drag gestures and display the shelf panel near the cursor. It does not read screen content or log keystrokes.
- **Crash Reporting**: No third-party crash reporting service is integrated.
- **Analytics**: No analytics or tracking SDKs are integrated.

## Contact

For privacy-related questions, please open an issue at [GitHub Issues](https://github.com/lazyfoxy33-dev/kubby/issues).
