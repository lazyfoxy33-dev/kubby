## Sobre

Mover ficheiros no Mac implica frequentemente alternar entre várias janelas do Finder. O Kubby resolve isso.

O Kubby é uma prateleira leve na borda do ecrã. Arraste ficheiros para dentro, navegue até ao destino e arraste-os para fora — três passos, sem complicações.

## Funcionalidades

- Prateleira na borda do ecrã, sempre disponível, nunca a atrapalhar
- Modo cursor — a prateleira aparece onde está a arrastar
- Vários ficheiros e pastas em simultâneo
- Sugestões inteligentes por tipo e histórico
- Modo claro e escuro

## Requisitos

- macOS 14.0 (Sonoma) ou posterior
