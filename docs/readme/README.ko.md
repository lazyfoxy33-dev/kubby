## 소개

Mac에서 파일을 이동할 때 Finder 창을 여러 개 열고 왔다 갔다 하시나요? Kubby가 해결해 드립니다.

Kubby는 화면 가장자리에 상주하는 가벼운 파일 선반입니다. 파일을 드래그해서 넣고, 목적지 폴더로 이동한 후 꺼내면 끝 — 세 단계로 완료.

## 주요 기능

- 화면 가장자리 상주, 항상 사용 가능, 바탕화면 차지 없음
- 커서 모드 — 드래그 중 선반이 커서 근처에 자동 표시
- 여러 파일과 폴더 동시 보관
- 파일 형식과 이력 기반 스마트 목적지 추천
- 라이트 및 다크 모드 지원

## 시스템 요구 사항

- macOS 14.0 (Sonoma) 이상
