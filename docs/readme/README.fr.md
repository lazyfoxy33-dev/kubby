## À propos

Déplacer des fichiers sur Mac implique souvent de jongler avec plusieurs fenêtres Finder. Kubby règle ça.

Kubby est une étagère légère logée en bordure d'écran. Faites glisser vos fichiers dedans, naviguez vers la destination, puis déposez-les — trois étapes, sans prise de tête.

## Fonctionnalités

- Étagère en bordure d'écran, toujours accessible, jamais gênante
- Mode curseur — l'étagère apparaît là où vous faites glisser
- Plusieurs fichiers et dossiers en même temps
- Suggestions intelligentes selon type et historique
- Modes clair et sombre

## Configuration requise

- macOS 14.0 (Sonoma) ou ultérieur
