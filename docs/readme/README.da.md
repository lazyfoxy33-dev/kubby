## Om

At flytte filer på Mac kræver ofte jonglering med flere Finder-vinduer. Kubby løser det.

Kubby er en let filhylde ved skærmkanten. Træk filer ind, naviger til destinationen og træk dem ud — tre trin, færdig.

## Funktioner

- Hylde ved skærmkanten, altid inden for rækkevidde, aldrig i vejen
- Markørtilstand — hylden dukker op, hvor du trækker
- Flere filer og mapper på én gang
- Smarte destinationsforslag efter type og historik
- Lys og mørk tilstand

## Systemkrav

- macOS 14.0 (Sonoma) eller nyere
