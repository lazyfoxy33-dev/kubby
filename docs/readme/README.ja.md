## 概要

Macでファイルを移動するとき、複数のFinderウィンドウを行き来していませんか？Kubbyが解決します。

Kubbyは画面の端に常駐する軽量なファイル棚です。ファイルをドラッグして入れ、目的のフォルダへ移動し、取り出す——3ステップで完了。

## 主な機能

- 画面端に常駐、いつでも使えて邪魔にならない
- カーソルモード——ドラッグ中にシェルフが自動表示
- 複数のファイルとフォルダを同時に保持
- ファイルタイプと履歴に基づくスマートな移動先提案
- ライト・ダークモード対応

## 動作環境

- macOS 14.0 (Sonoma) 以降
