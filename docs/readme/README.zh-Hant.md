## 簡介

在 Mac 上移動檔案，是否經常需要開啟多個 Finder 視窗反覆切換？Kubby 解決這個問題。

Kubby 是一個輕量的檔案暫存架，常駐螢幕邊緣。把檔案拖入 Kubby，導航到目標資料夾，再拖出——三步完成，無需切換視窗。

## 功能

- 螢幕邊緣常駐，隨時可用，不佔桌面
- 游標模式——拖曳時面板自動浮現在游標附近
- 支援同時暫存多個檔案和資料夾
- 智慧目標推薦，根據檔案類型和歷史紀錄推薦目標目錄
- 支援亮色與暗色模式

## 系統要求

- macOS 14.0 (Sonoma) 或更高版本
