## Über

Dateien auf dem Mac zu verschieben bedeutet oft, mehrere Finder-Fenster gleichzeitig zu verwalten. Kubby löst das.

Kubby ist eine leichte Dateiablage am Bildschirmrand. Ziehen Sie Dateien hinein, navigieren Sie zum Zielordner und ziehen Sie sie heraus — drei Schritte, fertig.

## Funktionen

- Bildschirmrand-Ablage, immer griffbereit, nie im Weg
- Cursor-Modus — Ablage erscheint direkt am Ziehpunkt
- Mehrere Dateien und Ordner gleichzeitig
- Intelligente Zielvorschläge nach Typ und Verlauf
- Hell- und Dunkel-Modus

## Systemvoraussetzungen

- macOS 14.0 (Sonoma) oder neuer
