## Om

Å flytte filer på Mac innebærer ofte å jonglere med flere Finder-vinduer. Kubby løser dette.

Kubby er en lett filhylle ved skjermkanten. Dra filer inn, naviger til destinasjonen og dra dem ut — tre trinn, ferdig.

## Funksjoner

- Hylle ved skjermkanten, alltid tilgjengelig, aldri i veien
- Markørmodus — hyllen dukker opp der du drar
- Flere filer og mapper samtidig
- Smarte destinasjonsforslag etter type og historikk
- Lys og mørk modus

## Systemkrav

- macOS 14.0 (Sonoma) eller nyere
