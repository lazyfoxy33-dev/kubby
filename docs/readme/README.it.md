## Informazioni

Spostare file su Mac spesso significa destreggiarsi tra più finestre Finder. Kubby risolve il problema.

Kubby è uno scaffale leggero sul bordo dello schermo. Trascina i file dentro, naviga alla destinazione e trascinali fuori — tre passi, nessun caos.

## Funzioni

- Scaffale a bordo schermo, sempre a portata, mai d'intralcio
- Modalità cursore — lo scaffale appare dove stai trascinando
- Più file e cartelle contemporaneamente
- Suggerimenti intelligenti per tipo e cronologia
- Modalità chiara e scura

## Requisiti

- macOS 14.0 (Sonoma) o successivo
