## Tietoja

Tiedostojen siirtäminen Macissa tarkoittaa usein useiden Finder-ikkunoiden hallintaa. Kubby ratkaisee tämän.

Kubby on kevyt tiedostohylly näytön reunalla. Vedä tiedostot sisään, siirry kohteeseen ja vedä ne ulos — kolme vaihetta, valmis.

## Ominaisuudet

- Näytön reunan hylly, aina käsillä, ei koskaan tiellä
- Kursoritila — hylly ilmestyy sinne, missä vedät
- Useita tiedostoja ja kansioita samanaikaisesti
- Älykkäät kohdesijainnit tyypin ja historian perusteella
- Vaalea ja tumma tila

## Järjestelmävaatimukset

- macOS 14.0 (Sonoma) tai uudempi
