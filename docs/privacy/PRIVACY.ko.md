## 데이터 수집

Kubby는 **어떠한 개인 데이터도 수집하지 않습니다**.

- **네트워크**: Kubby는 인터넷에 연결하지 않습니다. 페어링한 본인의 기기 사이에서만, 같은 LAN 안에서 직접 통신합니다(Bonjour/mDNS 검색 + 기기 간 직접 연결). 서버는 사용하지 않습니다.
- **파일**: 선반에 올릴 때 Kubby는 파일 경로 참조만 저장합니다(다음 실행 시 선반을 복원하기 위한 작은 로컬 캐시 포함). 참조는 사용자가 제거하거나 선반을 비울 때까지 유지됩니다. 파일 내용은 **사용자가 직접 꺼낼 때만** 같은 LAN 안에서 페어링한 기기 간에 직접 전송되며 서버를 거치지 않습니다.
- **스크린샷**: ‘스크린샷 자동 보관’을 켜면 Kubby는 보안 범위 책갈피를 통해 사용자가 선택한 스크린샷 폴더에 접근하여, 새 스크린샷을 파일 참조로 보관함에 추가하는 용도로만 사용합니다. 내용은 사용자의 Mac에 남으며 업로드되지 않습니다.
- **충돌 보고**: 서드파티 충돌 수집 서비스를 통합하지 않습니다.
- **분석**: 분석 또는 추적 SDK를 통합하지 않습니다.
