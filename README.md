# Kubby

**拖拽暂存架，从容移文件** — A drag-and-drop file shelf for macOS.

## 简介

在 Mac 上移动文件，是否经常需要打开多个 Finder 窗口，反复切换？Kubby 解决这个问题。

Kubby 是一个住在屏幕边缘的文件暂存架。把文件拖入 Kubby，导航到目标文件夹，再拖出——三步完成。

## 功能

- 屏幕边缘常驻，随时可用，不占桌面
- 支持同时暂存多个文件和文件夹
- 智能目标推荐，根据文件类型和历史行为推荐目标目录
- 支持亮色 / 暗色模式

## 系统要求

- macOS 14.0 (Sonoma) 或更高版本
